# 界面实施约束（既有规则摘录与本批落点）

## 既有依据

已读取个人资料库中的 `Quant_Foundry_Design_Spec_01-03_Foundation_Surface_Interaction_Layout.md` 的 Foundation、Surface Language、Interaction & Layout 相关章节，以及 `Quant_Foundry_04_Components_System_Map.html`。它们不是这次新提出的视觉方向。

继续使用：工作流优先；数据密集不靠缩小中文正文；连续 Sheet 表格而非卡片墙；Metric Band 作为少量指标的连续承载；Tabs 只切同一对象视图；反馈 Local First；状态同时有文字／图标，不只靠颜色。

复用仓库 `OverviewShell.tsx`、`Overview.css` 和已有 controls。主操作橙色、浅色工作面及现有字体变量不变。**不打包或另发字体文件**。已有页面尺寸与规范细节有出入时，不为本批顺带重写全部全局样式。

## 本批新页面的具体落点

- 主体中文按既有规范保持约14px；不要堆9–11px说明。数据默认右对齐并用等宽数字；技术值可用现有 monospace 变量。
- 目录是 Dense Sheet，详情是普通结构化页面。保留一个清楚的纵向滚动区域；宽数据表允许局部横向滚动，避免整页横向漂移。
- 同一局部操作区最多一个主要动作；默认文案面向用户，不放“旧发布体系已退役”“候选治理”之类迁移说明。
- 一级侧栏仍是“数据资产”；详情内用“概览 / 数据预览 / 更新与问题”，不新增第二套全局菜单。
- Header 显示名称、简短用途、当前状态和“查看当前数据”；技术标识放到可复制的展开区。后端没有可靠中文名称时可用准确、集中维护的展示别名，不改语义和数据身份。
- 不让普通用户默认输入 representation、partition、schema。能够使用服务端 `preview_key` 时直接预填；它只支持示例当前对象，不伪装成全市场任意查询。
- 加载保持结构；局部失败就近提示。目录旧结果可保留并注明读取时间；被撤销权限、质量限制或代次变化的数据结果必须撤下，不继续展示为当前有效内容。

## 界面验收

每个 UI 包提供真实可交互预览入口与截图，不只交描述。至少检查1440×900、1024×768及窄屏390px；这些是本批检查视口，不是新性能指标。窄屏可折行／局部横滚，不能让主动作、标题和错误提示不可见。键盘可操作，焦点可见；刷新与错误有可读状态提示。

复用原组件能实现就复用，不引入一套新 UI 框架、通用低代码页面引擎或新的设计系统站点。
