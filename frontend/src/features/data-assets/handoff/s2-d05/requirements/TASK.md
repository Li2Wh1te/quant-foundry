# S2-D05｜当前数据预览与分页一致性

**版本：v1.0｜第二阶段第一批｜建议角色：前端／交互**  
**依赖：S2-D01、S2-D02**  
**本包唯一交付结果：用户一次操作即可查看服务端提供的当前对象示例，跨页、错误和精度处理可靠。**

基于编包时main `4c9e8167d49ef1d6bbc49afc6578208d7a339f97` 的实际页面与接口，执行时从最新main接续。先读本文件，再看COMMON/API_NOTES/INTEGRATION中与本包相关部分。不需要拿到整个旧启动包。

## 目标与范围

只做有界数据预览，不做K线、任意标的搜索、完整报表导出或批量下载。默认对象来自`preview_key`，页面明确“当前对象示例”，不包装成已支持全部主体的业务浏览器。

## 实施

1. 点击“查看当前数据”后用descriptor的`preview_key`预填必要参数并执行一次有界查询；正常路径固定`allow_partial=false`。用户无需手填representation、schema或partition；没有preview_key时说明“暂无可预填对象”，不能伪造标的或业务键。
2. 默认使用该数据集已知且数量有界的业务列，保留必要身份用于分页和范围说明。列数遵守32上限；未完整声明业务列时提供技术预览标签，不改字段语义。`basis_state`可供诊断，用户默认不面对所有内部列。
3. 请求条件可在“调整查询”中按已知语义编辑。日期键只有契约确认是日期时使用日期控件；对象键保持文本。默认页面不做按日期猜测证券映射、复权或公司行动处理。
4. 游标只保存在当前条件的页栈；改变dataset、主体、范围、列、page_size或schema后清空页栈，取消旧请求。后端返回DATA_CHANGED或REBUILD_REQUIRED后清除旧结果并提示重读，不自动循环重试直到过关。
5. Decimal与大整数按原始字符串显示；纳秒不交给毫秒Date截断。空值显示“—”，false/0显示本值。页行数不换算对象数；报告节点跨页时明确这是片段，不自行拼装为完整财报/持仓报告。
6. 保留合理分页与局部横滚。响应中actual_range仅称“本页范围”；不把`request_satisfied=false`或未验证覆盖的结果描述为全范围完整。空页、查询范围无记录、数据集空、受限分别显示。
7. 原有“允许部分结果”不继续放在普通查询表单。若需保留维护者诊断能力，放入明确的高级诊断区域，需显式开启并全程标示“可能包含无效或撤回内容”；不向市场业务输出，不称为安全部分。不得自动把false改成true重试。
8. 认证失败、新质量拒绝、维护拒绝、代次变化时撤下旧预览。网络刷新失败保留同对象旧预览时必须注明旧读取时刻且禁止继续拼页；不得继续称作当前已验证值。

## 验收

| 场景 | 必须结果 |
|---|---|
| 有preview_key | 一次操作发一次合法query，无手工check，无来源标识要求 |
| descriptor.representation是v2布局 | 使用preview_key真实表示，不误传布局字符串 |
| 翻页期间generation变化或问题状态改变 | 清除过期结果和页栈，明确重新读取；不回退旧数据源 |
| 快速换对象/条件、组件卸载 | 请求取消，晚到响应不污染新对象 |
| Decimal、超安全整数、ns、null/false/0 | 显示不丢精度，不错填值 |
| 报告多页与request_satisfied=false | 仅称当前片段/本页，不伪造完整报告或日期覆盖 |
| 受限诊断 | 普通请求不启用allow_partial，诊断结果明确隔离 |
