# S2-D04｜数据集概览、字段与能力边界

**版本：v1.0｜第二阶段第一批｜建议角色：前端／UI**  
**依赖：S2-D01、S2-D02**  
**本包唯一交付结果：用户进入一个数据集后，能明白它提供什么、采用什么口径、哪些能力尚未声明。**

基于编包时main `4c9e8167d49ef1d6bbc49afc6578208d7a339f97` 的实际页面与接口，执行时从最新main接续。先读本文件，再看COMMON/API_NOTES/INTEGRATION中与本包相关部分。不需要拿到整个旧启动包。

## 目标与范围

只实现详情概览与字段说明，不实现新数据标准化、来源融合或通用业务查询接口。详情预览和更新问题通过预留组件由D05/D06交付。

## 实施

1. 从实际descriptor加载并显示名称、用途、频率、来源、当前状态。显示别名集中在D01模块，不在页面内复制数据集映射。未声明的语义显式标注，不能去掉“来源报告值／未锚定”等关键限定来美化名称。
2. 概览优先显示“能提供什么／已知限制”；主要动作为“查看当前数据”，导航至preview视图。它不是“发布”或“检查全部数据”，也不依赖用户手工提交一次后端check。
3. 显示字段名称、已声明含义、类型与计算限制。technical/path类信息按需展开；对于无法可靠翻译的字段保留技术名并标注未提供业务说明，不根据f0_前缀猜单位、币种、百分比或价格基准。
4. `updated_at`标注为目录/记录更新时间；`partition_range`只放技术区并注明存储范围、不证明业务连续覆盖；`row_count`只称物理存储行。业务截至日没有专用可信字段时显示未声明。
5. 技术区保留dataset/schema/rule/generation、源表示键等定位信息及复制操作；不展示旧发布历史、血缘图或版本切换。schema存在不等于字段语义已全部确认。
6. 切换dataset立刻撤下前一个对象内容并取消请求；局部字段表或问题面板错误不破坏其他已取得说明。当前字段表搜索只筛元数据，不触发业务读取。
7. 受限数据集仍可看说明；能否读某个实际范围交后端判断。空、不存在、尚未检查、暂不可读取区分显示。

## 验收

| 场景 | 必须结果 |
|---|---|
| 日线、净值、完整报告三类descriptor | 同一框架能解释不同结构，不编造统一口径 |
| 未知单位、decimal_text、未声明说明 | 不显示为元/百分比/可直接算；技术类型与业务含义分开 |
| 新旧dataset快速切换 | A的晚到返回不能覆盖B |
| 维护/受限/空 | 说明可查看时正常展示，数据权限不由UI推断 |
| 表字段较多 | 可搜索/滚动，标题、限制与返回始终可达 |
| 信息简化 | 默认无需阅读schema/分区标识，无历史版本入口 |
